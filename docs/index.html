📖 这是什么

Kiro Assistant（道 Agent）是一个本地透明代理插件。它在你本机起一个小代理，悄悄拦截 Kiro 发往云端的请求，把官方的"身份与规则"换成帛书《老子》与道藏《阴符经》之道魂，再原样转发到官方 AWS Q。模型从此不再自称 Kiro，而所有真实工具（读写文件、跑命令、终端）依旧全部可用。

核心理念：水善利万物而有静，天之道利而不害。只在通道中借力，不破坏 Kiro 本体、不强加任何模型、不破坏你正常的网络与使用体验。

✨ 核心特性

  • 透明代理：本机 HTTP 代理拦截 API，就地注入系统提示词。
  • 源头隔离：请求侧全替换 + 响应侧身份净化 + 历史 SP/工具隔离 + 幂等防重注。
  • 双模式：invert 注入 / passthrough 直连，落盘持久化、重启恢复。
  • VPN 友好：独立 relay 子进程绕过 Electron 网络栈，默认继承你的代理/VPN，失败回退直连。
  • 模型保全：永远转发你自己选择的模型，从不强制切换；免费/受限账号照常工作。
  • 软编码·为变所适：零硬编码，全部动态发现；诊断默认关闭，流式永不卡顿。
  • 跨平台：自动识别 Windows / macOS / Linux 的 Kiro 配置路径。
  • 代理常驻：独立进程运行，Kiro 重启不灭，watchdog 自愈。

🚀 安装

① 从 Releases 下载最新 kiro-assistant-<版本>.vsix。
② 命令面板 → Extensions: Install from VSIX... 选中文件。
③ 重启 Kiro → 命令面板 → Kiro Assistant: Start (invert)。
